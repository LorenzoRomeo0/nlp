Which words of the input pushed this output up, and which pushed it down?

Three ways to answer
  1. 1OcclusionRemove a word or a sentence and see how the output changes. Simple and robust; but removing text also changes everything around it.
  2. 2GradientsAsk how sensitive the output is to a tiny change in each word. Fast, but local and noisy.
  3. 3Integrated gradientsDo it along a path from an empty text to the real one, so that the contributions add up to the total change. More principled, but it needs a baseline.
What it shows how this output depends on this text. What it does not show why the model “chooses”: dependence is not a reason.
